# フェイスアバター（FaceMaskAvatar）

写真に写った顔を自動検出し、選択した顔をアバター画像やモザイクで加工できるiOSアプリです。

写真内の顔を個別に選択できるため、加工したい顔だけを隠し、残したい顔はそのままにできます。

アプリに用意されたアバター画像に加え、自分で用意した画像を取り込んで使用することもできます。

## 主な機能

- 写真内の顔を自動検出
- 顔ごとに加工対象を選択
- 選択した顔をアバター画像で置き換える加工
- 選択した顔に円形モザイクを適用
- 加工しない顔はそのまま保持
- アプリに用意されたアバター画像を使用
- 「写真」や「ファイル」からカスタム画像を取り込み
- 加工済み画像を写真ライブラリに保存
- 日本語・英語に対応

## 使い方

1. 加工したい写真を1枚選択します。
2. 自動検出された顔から、加工したい顔を選択します。
3. アバター加工またはモザイク加工を選択します。
4. 加工結果を確認し、写真ライブラリに保存します。

## 写真・画像の取り扱い

顔検出と画像加工は、利用者の端末内で行います。

加工済み画像は、利用者が保存操作を行うことで写真ライブラリに保存されます。元の写真を変更せず、加工済み画像を別の写真として保存する仕様です。

カスタム画像はアプリ内に保存されます。

## プライバシー

本アプリは、写真や顔画像を加工するために利用します。アプリの実装には、利用者の写真、顔画像、カスタム画像などを外部サーバーへ送信する機能はありません。

詳しくは、[プライバシーポリシー（日本語）](https://github.com/sorastudio-coder/FaceMaskAvatar/blob/main/privacy-ja.html)をご覧ください。
